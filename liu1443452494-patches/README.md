# Amane 自用补丁说明

本补丁集调整 Amane 的媒体库图片、NFO、演员信息、标签、海报检索、番号匹配和处理日志。

## 补丁内容

| 文件 | 修改内容 |
|---|---|
| `0001-library-images.patch` | 媒体库分别选择封面（thumb）、海报（poster）、缩略图（fanart）。fanart 复用资源目录中的封面原图；备用海报裁切直接读取原图，不依赖输出的 thumb。关闭 thumb 时不复制、覆盖或叠加其水印。不删除历史图片，不转换旧媒体库选择。 |
| `0002-nfo.patch` | 仅在 NFO 中省略导演，追加当前文件的中文字幕及有码／无码／破解标签；去重并保留顺序，连续输出全部 tag 后再输出同序 genre。原有 actor 节点、XML 转义和非法字符清理保留。演员标签的保存位置由 `0005-metadata-tags.patch` 统一到数据库。 |
| `0003-actresses.patch` | 仅修改路径模板的 `{actresses}`。沿用原有性别筛选，0 人保留 `Unknown`，1～3 人保留姓名，超过 3 人输出“多人作品”。不缩减数据库或 NFO 中的演员名单。 |
| `0004-actor-mapping.patch` | 每次取得影片刮削结果后、写入数据库前，按用户 XML 统一演员姓名。唯一匹配转换为标准名，歧义或未匹配保留原始输入并继续 Amane 原有流程。 |
| `0005-metadata-tags.patch` | 刮削保存时，将原始标签本地转为简体，再追加已完成姓名归一的完整演员名单，去重保序后写入数据库并同步标签关联。前端显示、标签筛选及 NFO 共用数据库标签。 |
| `0006-actor-delete.patch` | 删除演员时清理演员资料、别名及影片关联，不自动生成剔除规则；后续影片刮削可按 XML 标准名重新创建演员。同步调整演员列表、详情页的删除提示及智能体说明。已有剔除规则继续保留。 |
| `0007-image-quality.patch` | 封面与海报遍历有效候选，按实际文件大小择优；内置 Tenhow、ASIN 日亚及日文标题回退检索，保护下载海报不被较低尺寸的裁剪结果覆盖。 |
| `0008-processing-log.patch` | 影片详情页按番号分别显示最近一次刮削和整理记录；集中展示来源结果，合并请求重试及日亚搜索统计，保留检索信息、图片尺寸、文件大小、选择原因及最终地址。 |
| `0009-matching.patch` | 日亚已知数字版本去除固定版式后须与完整原题一致，并核对演员和商品身份；freejavbt 欧美紧凑链接须与卡片番号、片商和日期一致，只接收同站点链接。 |
| `0010-library-jpeg.patch` | 整理输出 JPG 时核对实际格式，JPEG 原样复制，其他格式仅转换库路径副本；遵循刮削设置中的 JPEG 质量，保留完整色彩采样，角标合并编码，刮削缓存保留原图。 |

NFO 的字幕标签沿用文件名和外挂字幕识别结果，不检查字幕实际语言；马赛克性质优先使用文件标记，再参考影片类型。破解不会额外自动追加有码或普通无码。自动生成的文件标记只用于当前文件的 NFO，不写入同一番号共用的数据库标签；刮削来源原本提供的同名标签继续保留。

标签使用保留原有用词的通用简体转换，不联网，也不需要启用或配置 LLM。只转换原始标签，演员姓名保留 XML 映射及原有别名处理后的结果。刮削保存仍尊重标签锁定及现有分类规则，不修改来源原始快照；手动编辑标签不触发自动转换或追加。

已存在的影片需要重新刮削、保存后才会获得数据库标签；允许复用原始刮削缓存，不必强制重新获取站点数据。已锁定的标签保持原值。磁盘上已有的 NFO 在下一次整理写入时更新，不进行自动批量回填。

自定义水印使用数据目录中的 `watermarks/`；`{number}` 的大小写沿用原有规则。

整理 JPG 转换不缩小像素尺寸，按 EXIF 校正显示方向，保留颜色配置，透明区域合成白底；封面、海报、fanart 和剧照均遵循 JPEG 质量设置。JPEG 编码仍有损，文件大小受原格式、画面内容和质量设置共同影响。已有 JPEG 不因格式统一而重编码；非 JPEG 的封面或海报需要角标时合并为一次编码。每次整理读取缓存原图，转换成功后才写入目标，解码或编码失败时保留旧图。已有缓存下次整理即可使用，不需要重新刮削。

## 演员姓名映射

固定读取当前数据目录根目录的 `mapping_actor.xml`，与 `config.toml`、`amane.db` 同级。

- Windows：通过软件菜单“打开数据目录”，将 XML 复制到该目录根目录。
- Docker：默认容器路径为 `/data/mapping_actor.xml`，在宿主机对应的数据挂载目录中维护文件。
- XML 由用户提供，不会自动下载、覆盖或随镜像内置。文件使用 UTF-8，支持 UTF-8 BOM。
- 每条 `a` 记录的 `zh_cn`、`zh_tw`、`jp` 与逗号分隔的 `keyword` 均参与完整姓名匹配，清除姓名两端的空白。
- 唯一匹配后使用该记录的非空 `zh_cn`。多个记录指向相同标准名不算歧义；同名对应不同标准名时跳过该姓名的映射。
- 每次刮削重新读取文件，修改后对下一次取得刮削结果的任务生效；缺少文件时继续原有流程。文件格式或编码损坏时，当前任务会报告明确的读取错误。
- 原始姓名交给项目已有的别名机制保留，供演员资料查询使用；性别、名单顺序和来源原始快照保留。
- 后续展示名修改和演员合并继续采用原有机制，不强制覆盖数据库展示名，也不迁移已整理的目录。

## 演员删除

需要按更新后的 XML 重新创建演员时，先维护 XML，再删除对应旧演员，随后重新刮削相关影片。影片的演员字段需要未锁定；通过扫描批量处理时，刮削范围需要包含“已刮削”。允许复用元数据缓存，XML 映射仍会重新执行，不需要重启。

数据库中已经保存的演员剔除规则不会自动清除。需要恢复对应演员时，在“演员 → 列表视图 → 分类规则”中移除其姓名及相关别名的剔除规则，再重新刮削。移除规则不会恢复旧演员资料；其他影片中被移除的演员关联需要各自重新刮削，文件夹和 NFO 需要重新整理。

## 高清图片

封面（thumb）与海报（poster）按实际文件字节数选择，不以像素数量或响应头中的大小代替。全部候选均参与检查；有效缓存可以复用，损坏图片和返回 HTML 的地址不参与排序。普通来源同大小时沿用字段优先级和站内顺序；海报同大小优先日亚，Tenhow 排在普通来源之后。

海报检索流程固定内置：

1. 收集普通刮削来源的海报候选。
2. 使用原始日文演员名，在 Tenhow 目录及必要的五十音子目录定位演员。核对同一作品区块中的 DMM 商品编号后，取得图片链接和 ASIN；图片下载失败不影响已核实 ASIN 的后续使用。
3. 使用 ASIN 访问日亚商品页，仅提取通过身份核对的商品主图，同时尝试主图原始地址和页面提供的缩放地址。
4. 未取得有效日亚图片时，使用清理后的日文标题搜索光盘与数字视频，最多追加一次缩短标题检索；网络失败不触发缩短重试。候选始终按完整原题与演员核对，已核实的新 ASIN 在日亚图片失败时继续尝试 Tenhow 直链。
5. 已取得的普通来源、Tenhow 和日亚图片共同按文件大小比较。ASIN 路径取得有效日亚图片后跳过标题搜索，即使该图片比已有海报更小。

检索信息按 DMM、AVBase、JavBus、其他合格日文来源选取，仅兼容已知 DMM 编号差异。搜索与结果核对清除当前作品番号、媒介标记及末尾演员名，保留完整正文；数字兑换码版本仅兼容已确认的无期限与 7 天期限版式，清理后须原题全等，不使用包含比例放行。禁止使用翻译标题或 XML 映射姓名，不改写来源快照。同一页面和图片地址去重，同 ASIN 新图仍参与比较。网络失败不永久判定 ASIN 无效。

裁剪继续遵守原开关、比例与触发条件，使用选定封面作为原图。裁剪结果宽、高均不小于下载海报且至少一项增大时才替换；同尺寸、较小、宽高各有优劣或裁剪失败时保留下载海报。裁剪结果按尺寸比较，不按重新编码后的文件大小比较。

新图全部失败时保留旧图；首次刮削没有旧图时继续原有缺图处理。原有下载设置、字段锁定和媒体库复制设置继续生效。fanart 继续复用封面原图。超分会覆盖资源目录中的原图，需要保留下载原图时应关闭超分。站点覆盖范围、页面变动及访问限制可能导致高清来源无结果，此时保留已取得的普通来源图片。

## 处理日志

片库详情提供“处理日志”，按番号分别读取最近一次刮削和整理，包含进行中及失败任务；两类并存时通过标签切换，默认刮削。紧凑弹窗固定标题、标签和刷新按钮，完整文件路径、来源结果与过程共用滚动区；短信息并排，来源结果直接展示。同一番号的多个文件共用记录，明细保留各自路径；批量整理仅显示当前番号，时间依据实际记录，任务状态与文件结果分别显示。

中文说明由程序 `logs/tasks/` 中的任务日志和来源结果生成，不调用 AI 服务。同一请求的开始、重试及终态更新首次记录；不同来源、商品、方法或文件分别显示，无法关联的并行请求独立保留。普通网址显示为来源、访问操作、搜索词或商品编号；最终图片地址仅展示一次。图片原始信息、尺寸、准确字节数、选中及裁剪原因继续保留，凭据脱敏，原始日志不变。图片检索与排序沿用 `0007-image-quality.patch`。弹窗打开时查询，活跃任务刷新已有记录，关闭后停止刷新。

日亚“搜索作品”汇总当前页面识别的结果条数、匹配条数、其中取得有效图片的条数，以及未通过条件的分类计数；同一卡片只记录首个排除原因。完整标题与缩短标题分别统计，网站明确无结果、列表未识别、请求或验证失败、匹配后缺少图片分别说明。统计合并到原搜索记录，不追加逐商品明细或链接列表；未记录数量的旧任务明确提示缺失。

旧任务中没有记录的路径、图片尺寸或文件大小明确提示缺失，不读取当前文件倒推历史。旧整理日志无法确认番号归属时不关联；任务删除或日志清除后不保留独立副本。日志缺失、损坏或过长时显示读取限制，不使用同批次其他影片的数据补充。
